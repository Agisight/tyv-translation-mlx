# AGENTS.md

Инструкции для ИИ-агентов (Claude Code, Codex и др.), работающих в этом репозитории.

## Цель проекта

Офлайн-перевод русский ↔ тувинский на устройствах Apple и честная оценка качества:

1. **NLLB v3 на MLX** — своя реализация M2M100 (`nllb_mlx.py`), f32 совпадает с PyTorch; int8/int4.
2. **Gemma 4 E4B + LoRA** — обучение в Colab (`colab/`), значимо лучше NLLB v3; MLX-версии 4/8 бит.
3. **Методика** — чистый тест (1369 пар), chrF++/BLEU/COMET, значимость, нормализованный chrF++.

Главный эталон: NLLB v3 на чистом тесте — chrF++ **49.2 / 49.1**. Gemma bf16 — **50.5 / 50.9**.
Текущий статус и все цифры — раздел «Статус» и таблица в `EXPERIMENTS.md`. Обновляй их после каждого шага.

## Окружение

- macOS, Apple Silicon, MacBook Air M4, 16 ГБ памяти, ~20 ГБ свободного диска.
- Python 3.12 из Homebrew в `.venv` (системный `python3` — 3.9, не использовать):
  `source .venv/bin/activate`, зависимости — `requirements.txt`.
- COMET — только в отдельном `.venv-comet` (`requirements-comet.txt`), иначе сломает основное окружение.
- zsh: не добавляй комментарии `#` в команды, которые пользователь вставит в терминал.
- Тяжёлое обучение и конвертация больших моделей — в Colab (A100, High-RAM), не на Маке.
- Перед `mlx_lm.convert` с Hugging Face нужен полный снапшот: `hf download <repo>`.

## Файлы

- `prepare_data.py` — данные. Тест по умолчанию = held-out тест NLLB v3 (`shuffle(seed=42)`,
  пары 2000–4000) без дублей train; `--keep-dup-test` — все 1999 пар. Версия датасета
  зафиксирована в `DATASET_REVISION`.
- `evaluate_nllb.py` — эталон NLLB v3 в PyTorch, настройки как при обучении v3.
- `nllb_mlx.py`, `convert_nllb_mlx.py`, `evaluate_nllb_mlx.py`, `bench_nllb_mlx.py` — NLLB на MLX.
- `colab/train_gemma4_tyv_colab.ipynb` — обучение/оценка/конвертация Gemma. Всегда «Выполнить все»:
  режим определяется сам; публикация (ячейка 10) и конвертация (ячейка 11) выключены по умолчанию.
- `significance.py`, `metrics_extra.py`, `comet_eval.py` — значимость, нормализованный chrF++, COMET.
- `make_human_eval.py`, `count_human_eval.py`, `human_eval_q4.csv` — ручная оценка носителем.
- `upload_*.py` — публикация моделей и карточек на Hugging Face.
- `eval_results_*` — сохранённые переводы, по ним считаются все метрики. Коммитятся.
- `legacy/qwen/` — ранний эксперимент Qwen3-1.7B на Маке (MLX LoRA). Не основной результат.

## Правила

1. **Тест не менять.** Сплит NLLB v3 + удаление дублей train, версия датасета зафиксирована.
   Не «улучшай» цифры другим тестом или другой метрикой. `eval_for_paper.ipynb` (train_test_split)
   — неверный сплит, пересекается с train NLLB, не использовать.
2. **Формат промпта** `ru→tyv: …` / `tyv→ru: …` одинаков при обучении и инференсе (`PROMPTS` в
   `prepare_data.py`). Меняешь — переобучай.
3. **Сравнение моделей** — только одним скриптом и одними настройками генерации
   (greedy, `max_new = 32 + 3 × длина входа`).
4. **Долгие операции** (обучение, полный прогон оценки, скачивание моделей, конвертация) не запускай
   без явной просьбы пользователя. Сначала предложи команду.
5. **Не коммить** `models/`, `data/`, `adapters/`, `.venv*/`, веса (`*.safetensors`).
6. **Карточки на Hugging Face** обновлять скриптами `upload_*.py`; повторный `push_to_hub`
   перезаписывает README автоматической заготовкой.
7. **Факты для статьи и резюме:** NLLB v3 — дообучение модели Meta на основе кода David Dale
   (с его консультацией), не написанная с нуля. Сокращение словаря, Core ML, MLX-порт — автора.
   Не приписывай результатов, которых нет в логах и `EXPERIMENTS.md`.
